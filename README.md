# streamflow-portugal-ungauged

Supplementary material (figures, tables, data and code) for the research paper on
**streamflow prediction at ungauged basins in mainland Portugal**.

👉 **[View the supplementary material page](https://foresight-ulisboa.github.io/streamflow-portugal-ungauged/)**

## Contents

| Path | Description |
|------|-------------|
| `index.html` | Main supplementary material page (GitHub Pages entry point) |
| `css/style.css` | Page stylesheet |
| `figures/` | High-resolution supplementary figures (PDF + PNG) |
| `tables/` | Supplementary tables (CSV) |

## Local preview

Open `index.html` directly in any modern browser, or serve it locally with:

```bash
python -m http.server 8000
# then open http://localhost:8000
```
